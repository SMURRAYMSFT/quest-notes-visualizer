    Quest Line

    Writing notes the journal understands

    Use normal Word styles. Nothing else required.

    • Heading 1 → a Quest
    • Heading 2 → a Stage / sub-quest
    • Bullet or numbered list item → an Objective
    • Plain paragraph under a heading → description text

    Markers you can sprinkle anywhere:

    • [x], [done] or ✓ at the start of an objective → completed
    • (optional) → optional objective
    • @Location → place chip  •  #tag → tag chip
    • Type: Main / Side / Faction / Misc  •  Level:, Giver:, Location:, Reward:, Requires:
    • Requires: Other Quest Name → draws the quest line

    Markdown / plain text works too: #, ##, -, - [x].
